A398184: numbers of maximal subsets of the n X n grid with no three collinear points, by size.
A maximal subset is one to which no further grid point can be added without creating a
collinear triple. Subsets are counted as sets of grid points; rotations and reflections
are not identified. Rows n = 1..7 were computed by two independent exhaustive programs
(attached to A398172 as a398172.txt); rows n = 8..10 by two independent exhaustive C programs
(see the GitHub link in A398172). The last entry of each row is A000755(n), the first size
is A277433(n) for n >= 3.
